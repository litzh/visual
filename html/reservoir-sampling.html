算法说明 How it works

function reservoir_sampling(stream, k):
    R = 前 k 个元素        # 先把蓄水池填满
    for i = k+1 .. n:
        j = random(1, i)  # 在 1~i 中均匀随机
        if j <= k:
            R[j] = stream[i]  # 以 k/i 概率替换
    return R
  • 当第 i 个元素（i > k）到达时，它以 k / i 的概率替换蓄水池中的某个随机槽位。
  • 第 i 个元素最终入选概率：(k / i) × (i / n) = k / n，其中后一项表示入选后不再被替换的概率。
  • 因此数据流中的每个元素最终被抽中的概率都是 k / n，与 n 是否已知无关。
  • 空间复杂度 O(k)，时间复杂度 O(n)。
