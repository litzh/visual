支持范围与寄存器映射说明

支持：int char void、全局/局部变量、一维数组、int*/char* 指针、 & *、++ --、算术/比较/逻辑/位运算（含 << >>）、 复合赋值、if/else while for break continue、函数定义/调用/return、 // 与 /* */ 注释、printf（%d %x %c %s %%）。
32 位语义：所有整数运算按 32 位补码回绕；int/指针 占 4 字节， char 占 1 字节（有符号，读取时符号扩展）；内存字节寻址、小端序。
伪 x86 寄存器约定：EAX 表达式结果/函数返回值，EBX 左操作数， ECX 比较与循环条件，EDX 右操作数，ESI 读取源地址， EDI 写入目标地址，ESP/EBP 栈指针/帧指针，EIP 伪代码地址。 函数调用按 x86 cdecl 风格压栈（参数从右到左、返回地址、旧 EBP）。 栈帧创建时局部变量区整体清零；尚未执行到的声明在调用栈中显示为“未初始化”。
不支持：预处理、struct/union/enum、switch、float/double、 多维数组、malloc、函数指针、原型声明、完整 ISO C 标准库。 本页不把任何未实现功能显示为可用。
